# 客廳家具配置模擬室

靜態、免相依套件的 Canvas 3D 比例模擬，無須 WebGL、CDN、登入或個人資料。依提供的平面圖（488 × 425 cm）及實景照片配色建模，包含黑皮沙發、粉棕方磚、米白牆、酒紅／米黃窗簾、右側電視櫃、狗區與收納區。材質、家具高度與小物簡化呈現，並非照片測量或施工圖。

## 模型

55 吋依 LG 台灣 55UA7550PTA 官方規格重建簡化外觀，非原廠 CAD／3D 檔。

- 不含底座：123.6 × 71.8 × 6.79 cm。
- 含底座：123.6 × 78 × 23 cm，腳座寬 108.6 cm。
- 60／65 吋沿用同外觀等比例放大，不宣稱為實際型號規格。
- 電視櫃 120 × 40 cm，位於配置圖右側；櫃高預設 65 cm 為估算，可調整。
- 茶几依照片中 40 cm 地磚重新估為 120 × 75 cm 長方形；長寬可調，推車及椅子獨立，非原始 70 × 70 cm 正方形。
- 固定家具尺寸與平面位置以使用者配置圖為基準，未標高度採示意值。牆高 280 cm 為估算。

官方資料：https://www.lg.com/tw/tv-soundbars/4k-uhd-tvs/55ua7550pta/

## 功能

55／60／65 吋、桌上／壁掛、櫃高／壁掛中心高度、茶几長寬調整；拖曳旋轉、滾輪／雙指縮放、鍵盤操作、沙發視角、肉球往外看及平面配置。即時計算櫃面外凸及比例模型腳座是否落在櫃面內。

執行 `npm run check` 檢查 JavaScript 語法與尺寸計算。全部資源在 dist，直接作為靜態目錄發布。

Sites 發布輔助腳本未安裝於此環境，使用接受 stdin 短期憑證的 Git 同步與 tar 封裝替代，憑證不落盤。瀏覽器啟動受執行環境限制；已完成尺寸與程式邏輯檢查，尚未完成真實瀏覽器排版驗證。

## 新舊電視與空間更新

新增「舊電視約 40 吋」按鈕；原型號未知，機身 95.35 × 57.31 cm 與中央腳座為通用估算，不當成實際產品規格。55／60／65 吋會顯示相對舊 40 吋的畫面面積倍數。後牆門組中心為房寬的 244 cm；紅圈狗區改為黑色金屬欄杆狗屋，平面 170 × 70 cm，高度 95 cm 為示意。

## 沙發比較

雙沙發組、L 型與單組沙發；主沙發 160–240 cm、次沙發 120–200 cm，深度 80 cm；L 型延伸 60 cm。主沙發可靠下牆或左牆，黑色、米色、灰色可切換。3D 與平面同步，外觀為通用示意，非商品販售。

肉球視角：攝影機位於狗屋內 (451,52,110) cm，朝客廳 (165,58,280) cm 觀看；52 cm 為視覺示意眼高。

新增尺寸顯示切換、點孩子加速跳躍、狗狗出屋至電視往返、阿嬤回家與抱抱、姨姨牽機車進出。角色路線由 events.js 定義；機車停在狗屋前 (365,105) cm，狗路線避開停車範圍。40 吋舊機為通用厚邊框估算，螢幕比例以40吋16:9計算，機身非原廠規格。
