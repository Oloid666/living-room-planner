# 客廳家具配置模擬室

依 488 × 425 cm 配置圖與實景配色的靜態互動 demo。免安裝、免登入，入口為 index.html。

- 舊電視約 32 吋（照片估算）、LG 55UA7550PTA、60／65 吋比例比較。
- 桌上／壁掛切換與高度調整。
- 沙發款式、尺寸、顏色與靠牆擺放比較。
- 可調茶几、黑色金屬狗屋、置中門與狗屋內往外看的肉球視角。

55 吋依 LG 官方尺寸建立簡化模型，非原廠 CAD；舊電視為目測估算，60／65 吋為比例示意。沙發為通用外觀、家具高度與茶几為估算，非施工或商品規格。
